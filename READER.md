# Scripture reader

- **Version** changes the complete chapter and is remembered across visits. KJV, NKJV, NIV and Japanese Colloquial (口語訳, 1954/1955) are bundled locally. Scripture reading and per-verse version switching never request an external Bible service.
- KJV stays in `public/bible/`. NKJV is in `public/bible/NKJV/` and Japanese is in `public/bible/JPKJV/`. Each edition contains 66 book files with the identical KJV schema: `{ "book": "Genesis", "chapters": [{ "chapter": "1", "verses": [{ "verse": "1", "text": "…" }] }] }`. These assets are copied into `dist/bible/` by the production build. A hosted website still needs access to its own host to fetch book files; bundling does not install a service worker or make the entire website available offline.
- NKJV was imported from [Bolls Bible's bulk download](https://bolls.life/static/translations/NKJV.zip). Japanese was imported from [FujiHaruka's Colloquial Bible source](https://github.com/FujiHaruka/bible-api), which preserves complete text and uses compatible chapter numbering. `source.json` in each folder records the source, timestamp and counts. Japanese combined verse groups are retained once under the first numbered verse, and lettered parts are joined; the original grouped references are listed in the metadata. No passages are machine-translated.
- To regenerate, run `npm run import:translations` with Node and installed Edge on Windows (or an installed Playwright Chromium elsewhere). For already-downloaded source files, run `node scripts/import-translations.mjs --source-dir <directory>` containing `NKJV.json` and the extracted `create-table.sql`. The importer validates the complete edition before writing book files and strips provider HTML with a real DOM parser.
- Each verse has a **language icon** beside its copy action. Choose KJV, NKJV, NIV or Japanese to replace only that verse. These overrides are held in memory, reset on refresh or when changing the chapter edition, and never alter your saved chapter preference. Copy uses the currently displayed text and includes its actual edition. Bookmarks, notes and saved highlights have been removed. If an edition does not separately number a verse, the original text remains visible with an explanation.
- Highlight a word or short phrase (up to 240 characters) to open its **meaning card**. This works with mouse, touch selection and keyboard selection. The bundled glossary explains common biblical terms, phrases and older English; existing people/place notes also supply context. A local [Princeton WordNet](https://wordnet.princeton.edu/) dictionary adds 24,136 word/phrase entries and 4,611 inflected forms, built from the vocabulary of the English Bible editions. Its license is included in `public/dictionary/LICENSE.txt`; regenerate with `npm run build:dictionary`. Unknown English words can fall back to the [Free Dictionary API](https://dictionaryapi.dev/), which needs internet access. Unrecognized phrases show individual word meanings and the corresponding bundled NIV/NKJV verse, rather than an invented phrase interpretation. Japanese selections use matching glossary terms and the English verse context. Close with Escape or the close icon.
- The browser tab uses a custom open-Bible, cross and clock-face SVG mark for Canon & Chronos.
- **NIV** is bundled in `public/bible/NIV/`, using the user's `bible-niv.txt`. It contains all 66 books, 1,189 chapters and 31,086 numbered verses. The supplied export has unnumbered lines, abbreviated book headers, Psalm headings and seven combined lines. The importer splits those combined lines at reviewed boundaries, validates every Psalm boundary and verifies a complete text round trip for every book. Sixteen verse references omitted in this NIV source retain their numbering gaps; no other translation is substituted. `source.json` records the input SHA-256, split boundaries and omitted references. The supplied file does not specify its edition year. Regenerate with `node scripts/import-niv.mjs <path-to-bible-niv.txt>`.
- Study titles cover all 66 books and 1,189 chapters. Titles use the first section heading from the public-domain [Berean Standard Bible USFM](https://bereanbible.com/bsb_usfm.zip), independent of the selected edition. They are study aids, not canonical scripture. Regenerate with `powershell -ExecutionPolicy Bypass -File scripts/import-chapter-titles.ps1 -Archive <downloaded-zip>`.
- Chapter navigation resets to the reader's top. Explicit verse links retain their target. Read aloud has adjustable speed and voice selection, speaks scripture without verse numbers, and automatically continues across chapters and books. Manual navigation, changing edition, leaving the reader or pressing Stop cancels it. Japanese editions select Japanese voices.

## Verification

Run `bun run build`. For browser regression checks, start `bun run dev --host 127.0.0.1` and run `bun run test:e2e` (or `node node_modules/@playwright/test/cli.js test`). Tests use installed Windows Edge by default; set `PLAYWRIGHT_EXECUTABLE_PATH` to use a different compatible browser executable. Screenshots are saved to ignored `test-results/`.
